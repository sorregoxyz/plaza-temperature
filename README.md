# Daily Heat Register, Murcia 2026 

The artifact is built from a CSV dataset fed by the daily temperature register at Plaza Europa at four times: 9:00, 13:00, 17:00, and 21:00 from May to September, 2026. I took the daily temperature measurements using a handheld hygrometer.
